# INKUBIO — заметки для Claude (передача работы)

Сайт инкубатория INKUBIO (Узбекистан): 3D-история «от яйца до доставки» на three.js + информационный
блок + форма заказа (заявки уходят в Telegram/на почту). Хостинг: Render.com (`render.yaml`), сайт
inkubio.onrender.com. Владелец общается по-русски, коротко; хочет «максимально реалистично и красиво».

## Как устроено

- `server.js` — Node-сервер без фреймворков: раздаёт статику, `POST /api/order` (проверка, Telegram,
  почта, копия в `orders.csv`). Запуск: `npm start` (порт 5173). Нужен Node ≥ 22.9.
- `index.html` — вся разметка; 3D-история — фиксированные оверлеи `.ov` с `data-show` (в vh прокрутки).
- `js/main.js` — сцена, камера, хронология по прокрутке `t` (главы: `T = { intro 0, metrics 120,
  inc 300, hatch 750, alive 1000, line 1250, end 1800 }`), качество (тиры high/mid/low с автоснижением
  FPS), форма заказа, калькулятор доставки и т.д.
- `js/chick.js` — цыплёнок (меховые «оболочки»-слои), `js/egg.js` — яйцо и скорлупа (раскол, крышка),
  `js/embryo.js` — развитие эмбриона, `js/incubator.js` — шкаф-инкубатор, `js/line.js` — ангар/склад,
  конвейер, вакцинация, коробки, `js/truck.js` — грузовик-рефрижератор, погрузчик, `roundBox()`,
  `js/studio.js` — окружение и `FilmShader` (цветокоррекция, виньетка, зерно), `js/finale.js` — цыплёнок
  в блоке «О нас», `js/calc.js` — калькулятор окупаемости, `js/dmap.js` — карта доставки,
  `js/proof.js` — фото/отзывы, `js/contact.js` — статус «на связи», `js/config.js` — данные владельца.
- `js/i18n.js` — **три языка**: UZ (латиница, по умолчанию), RU, EN. Русский текст = ключ словаря `D`,
  значение `[uz, en]`. Статичная страница переводится обходом текстовых узлов и атрибутов; скрипты
  вызывают `window.I18N.t('русский текст', {vars})`. Нет перевода → строка в `I18N.missing` (консоль).
  Переключатель языка с флажками — в шапке (`#langBox`), выбор в `localStorage` и `?lang=uz|ru|en`.
  Значения, уходящие на сервер (порода, сегмент), остаются русскими; в заявке есть поле `lang`.
  Узбекское «oʻ/gʻ» пишется знаком `‘` (U+2018); в шрифте Unbounded этот знак подменён глифом
  Manrope (`css/fonts.css`, иначе он рисуется как «6»).

## Что сделано в этой сессии (по порядку, все коммиты в `main`)

1. Три языка + переключатель с круглыми флажками (UZ/RU/EN). Надписи на 3D-моделях тоже переводятся.
2. Плашка «🇺🇿 Из Узбекистана» над первым заголовком и «Сделано в Узбекистане» в подвале
   (флаг в шапке рядом с логотипом владельцу не понравился — убран).
3. Цыплёнок по референсу владельца (пушистый, светлый, в треснувшей скорлупе, золотое свечение):
   нижняя половинка скорлупы стоит вертикально, цыплёнок встаёт в ней; позади — золотой «яйцевидный»
   ореол; пол — сено (текстура) + соломинки (InstancedMesh); мягкие тени под скорлупой и цыплёнком.
4. Цыплёнок **выпрыгивает из скорлупы** (`JUMP_A..JUMP_B` = 1040..1064) и приземляется на сено
   (`LAND`), пищит; камера раздвигает кадр (`PAIR_DX`, `pairY`, `pairK`) и стыкуется со сценой линии.
5. Склад: реалистичный грузовик (кабина в фирменном зелёном, ливрея, колёса с дисками), гофрокоробки
   (скотч, отверстия, ручки), полные стеллажи с этикетками, паллеты в стрейч-плёнке, штабели закрытых
   коробок, погрузчик с паллетой ездит по проходу, атмосфера: лучи из окон и ворот, пыль, дымка,
   тёплый свет, приглушённые отражения окружения (`envMapIntensity *= 0.35` для ангара).
6. Кинематографическая цветокоррекция в `FilmShader` (все сцены); луч студийного света на первом экране.
8. Логотипы партнёров на первом экране, слева и справа под шапкой (`.partners` в `index.html`, стили в
   конце `css/style.css`): Министерство сельского хозяйства РУз (герб) и Parrandasanoat (ассоциация
   птицеводов). Круглые медальоны в `img/partners/` вырезаны из картинок владельца; названия — текстом
   (переводятся через i18n). Адаптив проверен на 1440, 390 и 320 px.
9. **Панель управления `/admin`** (`server/admin.js` — API и хранение, `server/admin.html` — интерфейс):
   статистика (анонимные «маяки» из `js/track.js` → `POST /api/hit`), заявки со статусами, новости на трёх
   языках с фото (`js/news.js`, блок `#news`), редактирование информации на сайте. Сохранённое отдаётся
   `GET /api/content` и накладывается на `SITE` в конце `js/config.js` (top-level await). Вход — пароль
   `ADMIN_PASSWORD`, подписанная cookie (HttpOnly, SameSite=Strict), проверка Origin, лимит попыток.
   Всё, что приходит из панели, проверяется на сервере (`cleanContent`, `cleanNews`), фото — по сигнатуре
   файла; на сайте тексты из панели вставляются как текст (`escHtml` в main.js). Данные — в `DATA_DIR`
   (по умолчанию папка `ORDERS_FILE`, локально `data/`). Даты по-узбекски — `I18N.date()` (в браузерах
   нет узбекских месяцев).
7. Производительность: упрощённая геометрия слоёв пуха (`shellGeometry` в chick.js), лёгкие яйца в
   лотках инкубатора, меньше слоёв пуха у цыплят линии, ниже pixel ratio и MSAA на телефонах,
   автоснижение качества при FPS < 42.

## Важные грабли

- В `main.js` функция перевода называется **`say()`**, не `tr`/`t`: внутри `update()` есть локальные
  переменные `t` (время сцены) и `tr` — однажды это уже ломало сцену инкубатора («tr is not a function»).
- Новые русские строки на странице или в скриптах — **добавлять в словарь `js/i18n.js`** (uz + en).
- В `main.js` уже заняты имена `track` (дорожка прокрутки) и `t`/`tr`; статистика — функция `stat()`.
- Значения из панели бывают объектами `{ ru, uz, en }` — выводить через `say()` / `I18N.t()`.
- three.js r160 (в `vendor/`), без `scene.environmentIntensity`; аддоны — только те, что лежат в
  `vendor/three/jsm`. Скруглённые коробки — `roundBox()` из `js/truck.js`.
- Тонмаппинг ACES уводит чистый жёлтый в оливковый — цыплят красить тёплым (`#ffd25a`).
- Перед выкладкой прогонять сцены и смотреть ошибки (см. ниже). Следить за нагрузкой: на линии
  ≈ 750–790 тыс. треугольников и ≈ 900–970 вызовов отрисовки за кадр (раньше было до 1,6 млн).

## Проверка

```bash
npm start                      # http://localhost:5173
```
Полезные параметры URL: `?t=1100` (сразу в нужный момент истории), `?lang=uz`, `?q=high|mid|low`
(зафиксировать качество), `?prof` (тайминги кадров в `window.__prof`, объекты в `window.__dbg`),
`?demo` (примеры фото/отзывов/карты). Playwright + Chromium в облачной среде рисуют WebGL через
SwiftShader: `chromium.launch({ args: ['--use-gl=angle', '--use-angle=swiftshader', '--ignore-gpu-blocklist'] })`,
загрузка сцены ~30 с; прокрутка к моменту `t`: `scrollTo(0, t * innerHeight / 100)`.

## Выкладка

Render автодеплой из `main` у владельца срабатывал не всегда — после пуша может понадобиться
в панели Render: **Manual Deploy → Deploy latest commit**, затем Ctrl+F5 на сайте.

## Идеи на будущее (владелец просит «ещё лучше»)

- Инкубатор крупным планом: конденсат на стекле, блики ламп, тёплое свечение лотков.
- Склад: рабочие в жилетах, больше жизни на заднем плане (без потери FPS).
- Линия упаковки: сократить вызовы отрисовки (объединить слои пуха цыплят линии / инстансинг).
- Реальные данные владельца в `js/config.js`: телефон, адрес, цены, фото, отзывы, города доставки.
