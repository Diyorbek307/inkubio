# INKUBIO — сайт инкубатория

3D-история «от яйца до доставки» + форма «Заказать цыплят», заявки с которой приходят на почту.

## Запуск

Нужен Node.js 22.9 или новее.

```powershell
npm install
npm start
```

Сайт откроется на http://localhost:5173.

## Настройка почты

1. Скопируйте `.env.example` в `.env`.
2. Укажите в `MAIL_TO`, куда приходят заявки (можно несколько адресов через запятую).
3. Укажите SMTP ящика, **с которого** уходят письма:

| Почта   | SMTP_HOST        | SMTP_PORT | Пароль                                                        |
|---------|------------------|-----------|---------------------------------------------------------------|
| Gmail   | `smtp.gmail.com` | 465       | «Пароль приложения» (нужна двухэтапная аутентификация)        |
| Яндекс  | `smtp.yandex.ru` | 465       | Пароль приложения в Яндекс ID → Безопасность                  |
| Mail.ru | `smtp.mail.ru`   | 465       | «Пароль для внешних приложений» в настройках безопасности     |

4. Перезапустите `npm start`. В консоли должно появиться `✓ SMTP … — заявки уходят на …`.

Обычный пароль от почты не подойдёт: почтовые сервисы требуют отдельный пароль приложения.

## Что происходит с заявкой

- Сервер проверяет имя, телефон, породу и количество; при ошибке посетитель видит подсказку.
- Письмо уходит на `MAIL_TO`, в теме — порода, количество и имя клиента.
- **Каждая** заявка дополнительно записывается в `orders.csv` (открывается в Excel) со статусом
  «отправлено», «ошибка отправки» или «почта не настроена» — так ни одна заявка не потеряется,
  даже если почта временно недоступна.
- Защита от спама: скрытое поле-ловушка и не больше 5 заявок с одного IP за 10 минут.

`.env` и `orders.csv` содержат пароль и личные данные клиентов — не выкладывайте их в публичный доступ
(они уже добавлены в `.gitignore`).

## Хостинг

Подойдёт любой хостинг с Node.js (VPS, Render, Railway, Timeweb Cloud и т.п.): загрузите папку,
задайте переменные из `.env.example` в настройках хостинга и запустите `npm start`.
Если сайт стоит за nginx или прокси хостинга, добавьте `TRUST_PROXY=1`.
Обычный «статический» хостинг без Node.js не подойдёт — письма отправляет сервер.

## Сайт в интернете прямо с этого ноутбука

Двойной щелчок по **«Запустить сайт.cmd»** в папке сайта. Через 10–30 секунд откроется браузер
с публичной ссылкой вида `https://….trycloudflare.com` — она же скопирована в буфер обмена и записана
в файл «ссылка на сайт.txt». Отправляйте её кому угодно.

- Сайт работает, пока открыто окно «INKUBIO — сайт в интернете» и ноутбук не спит
  (в настройках питания Windows можно запретить сон при работе от сети).
- При каждом запуске ссылка новая. Постоянный адрес — свой домен (через Cloudflare) или VPS (ниже).
- Заявки сохраняются в `orders.csv` в папке сайта; почта и Telegram — из `.env`, как обычно.
- **Заявки в Telegram:** двойной щелчок по **«Подключить Telegram.cmd»**. Он попросит токен бота
  из @BotFather, найдёт чат, где вы написали боту (личный или группа команды), пришлёт проверочное
  сообщение и запишет настройки в `.env`. После этого перезапустите сайт.
- Нужна программа cloudflared (Cloudflare): при первом запуске скачивается сама в
  `%LOCALAPPDATA%\inkubio`, подпись проверяется.

## Свой сервер (VPS)

**Самый быстрый способ — прямо с сервера, без ноутбука.** Зайдите на сервер (`ssh root@<IP>`) и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/Diyorbek307/inkubio/main/deploy/install.sh | bash -s -- ваш-домен.com
```

Скрипт скачает сайт с GitHub, поставит всё нужное, спросит пароль админки (и, по желанию, Telegram)
и запустит сайт с HTTPS. Обновить сайт после изменений на GitHub — та же команда.

Второй способ — с ноутбука, из папки сайта:

Всё нужное лежит в папке `deploy/`. Сервер: Ubuntu 22.04/24.04, 1 ядро, 1–2 ГБ памяти.
При создании сервера в панели хостинга добавьте SSH-ключ — содержимое файла
`%USERPROFILE%\.ssh\inkubio_deploy.pub`. Затем с этого ноутбука:

```powershell
powershell -ExecutionPolicy Bypass -File .\deploy\deploy.ps1 -Server <IP-адрес>
```

Скрипт сам поставит Node.js и Caddy (HTTPS-сертификат выпускается и продлевается автоматически),
запустит сайт как службу (перезапуск при сбое и после перезагрузки сервера), закроет лишние порты.
Без домена сайт откроется на `https://<IP>.sslip.io`. Когда купите домен — направьте его A-запись на IP
и запустите тот же скрипт с `-Domain ваш-домен.ru`. Обновить сайт после правок — тот же скрипт.

Пароли почты, Telegram и `/admin` — в файле `.env` на ноутбуке: скрипт загрузит его на сервер
отдельно от сайта (`/opt/inkubio/.env`). Заявки на сервере: `/var/lib/inkubio/orders.csv` и страница `/admin`.

## Панель управления (`/admin`)

Включается паролем `ADMIN_PASSWORD` в `.env` (на сервере — тот же файл, его загружает `deploy.ps1`).
Вход — `https://ваш-сайт/admin`.

- **Обзор** — посетители, просмотры, заявки и конверсия по дням; языки, устройства, откуда пришли,
  до какой главы досматривают историю. Без cookies, IP-адресов и личных данных (`js/track.js`).
- **Заявки** — все заявки с сайта, статусы «новая / в работе / выполнена / отказ», поиск, выгрузка для Excel.
- **Новости** — добавить, изменить, удалить; на трёх языках, с фото. Опубликованные видны на сайте
  в блоке «Новости» (`js/news.js`).
- **Информация на сайте** — контакты, часы работы, цены, ближайшие выводы, цифры компании, фото,
  отзывы, города доставки. Сохранённое применяется поверх `js/config.js` сразу, без перезапуска.

Данные панели хранятся рядом с заявками: на VPS — `/var/lib/inkubio` (`content.json`, `news.json`,
`stats.json`, `order-status.json`, папка `uploads/` с фото), на ноутбуке — папка `data/`.
На бесплатном Render диск стирается при каждом обновлении сайта — для панели нужен VPS.

## Отладка

`http://localhost:5173/?t=700` открывает историю сразу на нужном моменте (число — позиция прокрутки в vh).

## Что где настраивается

- `js/config.js` — контакты, Telegram/WhatsApp, Яндекс Метрика, цены для калькулятора, ближайшие выводы, цифры компании. Пустые значения — блоки скрыты.
- `.env` — почта и Telegram для заявок, пароль панели управления (`ADMIN_PASSWORD`).
- `img/logo.svg` — логотип (шапка сайта, иконка вкладки). Те же фигуры рисуются на грузовике, коробках
  и шкафу-инкубаторе из `js/logo.js` — если меняете логотип, поменяйте оба файла.
- `privacy.html` — политика конфиденциальности, данные организации выделены жёлтым.
- `photos/` + `photos` и `reviews` в `js/config.js` — фото «Как мы работаем» и отзывы клиентов.
  Пока списки пустые, блоки скрыты. Отзывы — только настоящие и с согласия клиента.
  Предпросмотр с примерами: `/?demo`.
- `schedule` в `js/config.js` — часы работы для кнопки «Позвонить» («На связи сейчас» / «Ответим с 8:00»)
  и часовой пояс инкубатория. Номер для звонка — `phoneLink`; пустой — кнопок звонка нет.
- `deliveryMap` в `js/config.js` — карта доставки: зоны (км, срок, пояснение) и города — координатами
  или просто «км по дороге + направление». Пока городов нет, блок скрыт. Город из карты приходит в заявке.
- `calc` в `js/config.js` — калькулятор окупаемости: стартовые цены корма и продажи, сохранность,
  свои данные роста по кроссам. Цена цыплёнка берётся из `prices`.

## Полезные адреса

- `/admin` — панель управления (пароль из `ADMIN_PASSWORD`), см. раздел «Панель управления».
- `/?q=low|mid|high` — принудительно выбрать качество графики (автоматическое понижение при этом выключено).
- `/?prof` — замеры кадров в консоли: `__prof` = [момент, мс на логику, мс на отрисовку, вызовы, треугольники, шейдеры].
- `/?debug` — включить проверку ошибок шейдеров (на рабочем сайте выключена: на видеокартах Intel она даёт рывки).
- `/?gate` — показать вступительную заставку, даже если вход уже был (вход происходит сам после загрузки).
- `/?promo=1` — чистый кадр без кнопок, для записи ролика.
- `promo/inkubio-reel-music.mp4` — вертикальный ролик 1080×1920 с музыкой, `promo/soundtrack.wav` — сам трек (собственная генерация, без чужих прав).
